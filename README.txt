FILES
-----
1. index.html
   The agency website (single file, opens in any browser).
   Includes: Welcome splash, availability banner, hero (AN AGENCY TRIO),
   works grid, Free Sample gallery (4 switchable demo sites:
   Keet Cafe / Iron Gym / Aura Studio / Urban Threads),
   trio cards, contact form, IST clock.

2. KURO_Brand.html
   Brand identity sheet: palette (Ink #0B0B0C / Paper #F5F2EF /
   Acid #C8E634), 4 logo concepts, hero demo.

3. Style_Reference.html
   Batch-1 style library: 9 color palettes extracted from reference images.

4. Trend_Styles.html
   Batch-2 style library: 6 live style demos (Typography-led, Brutalism,
   Experimental, Botanical, Maximalism, Dark Monochrome) + ZARZ container style.
